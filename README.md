# xamjiang/homebrew-tap

Homebrew formulae for [xamjiang](https://github.com/xamjiang)'s tools.

```sh
brew install xamjiang/tap/ghosts
```

| Formula | Description |
|---|---|
| [ghosts](https://github.com/xamjiang/ghosts) | Find and stop forgotten dev servers and Docker containers |

Formulae in `Formula/` are updated automatically by each project's release workflow.
